## 数据文件一览

| 文件名 | 类型 | 说明 |
|--------|------|------|
| `FMart_促销方案信息` | 维度 | 满减/折扣/新人券等 |
| `FMart_门店信息` | 维度 | 40 店，旗舰/标准/社区/前置仓 |
| `FMart_商品目录` | 维度 | SKU、品类、定价、损耗率 |
| `FMart_会员信息` | 维度 | 会员画像与等级 |
| `FMart_会员行为明细` | 事实 | 浏览→…→评价（约 56 万行） |
| `FMart_订单明细` | 事实 | 金额、毛利、促销、渠道、配送 |
| `FMart_日期维度` 等 | 辅助 | 日历、漏斗阶段、品类字典等 |

### 核心口径（摘要）

```text
毛利率     = SUM(毛利_元) / SUM(订单金额_元)
漏斗转化   = COUNTD(阶段会员) / COUNTD(浏览会员)   # 会员 UV
30分钟达   = COUNT(配送时长_分钟 <= 30) / COUNT(订单)
促销渗透率 = COUNT(促销ID <> 'P01') / COUNT(订单)
目标完成率 = 期间 GMV / 年度GMV目标_元
```

## 表关联（星型）

- 行为 / 订单 ← `会员ID` / `商品ID` / `门店ID`
- 订单 ← `促销ID`；商品 ← `品类ID`
- 订单.`关联事件ID` ↔ 行为.`事件ID`（支付事件派生订单）

## 注意事项

- 所有公司名、人名、价格均为**随机虚构**，不代表真实企业经营数据
- 本仓库为作品集交付包（数据 + 看板 + 报告），未包含造数脚本与面试备忘材料
